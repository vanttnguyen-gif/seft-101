# Todo App with Grid Mode

A simple and elegant todo list application with dual display modes.

## Features

- ✅ Add, complete, and delete todo items
- ✅ **List View** - Traditional vertical list layout
- ✅ **Grid View** - Modern card-based grid layout  
- ✅ Persistent view preference (remembers your choice)
- ✅ Responsive design - works on all screen sizes
- ✅ Smooth animations and hover effects
- ✅ Click items to mark complete/incomplete

## How to Use

1. Open `index.html` in your browser
2. **Switch Views:** Click the List (☰) or Grid (⊞) buttons in the header
3. **Add Items:** Type in the input field and click "Add"
4. **Complete Items:** Click on any item to toggle completion
5. **Delete Items:** Hover and click the × button

## View Modes

### List View (Default)
- Full-width items
- Alternating row colors
- Compact vertical layout
- Perfect for quick scanning

### Grid View
- Card-based layout
- Responsive columns (auto-adjusts to screen size)
- Hover effects with elevation
- Modern, visual design

## Technical Details

- Pure JavaScript (ES5) - no frameworks required
- CSS Grid for responsive layout
- localStorage for persistence
- Cross-browser compatible
