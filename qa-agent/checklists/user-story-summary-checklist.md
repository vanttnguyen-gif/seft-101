# User Story Summary Checklist

Use this checklist to validate `user-story-summary.md`.

## Completeness

- [ ] **Project overview** is filled in (name, users, scope).
- [ ] **Sources** section lists where stories came from.
- [ ] **All stories captured** from source(s) (no obvious omissions).
- [ ] **Stories grouped** by feature/module or journey.
- [ ] **Business rules** captured separately from ACs.
- [ ] **NFRs** included or explicitly marked as unknown.

## Clarity & Testability

- [ ] Each story has a **stable ID**.
- [ ] Narrative follows **As a / I want / so that** format (or equivalent).
- [ ] Acceptance criteria are **observable and testable**.
- [ ] Ambiguities are tracked in **Open Questions**.
- [ ] Assumptions are listed and labeled.

## Traceability

- [ ] Dependencies between stories/modules are noted.
- [ ] Related stories are cross-referenced where applicable.
- [ ] Any new stories/steps added are labeled **(Suggested)** with rationale.
