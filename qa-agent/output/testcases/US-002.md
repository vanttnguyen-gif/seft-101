# Test Cases — US-002: Mark todo as complete/incomplete

## User Story

- **US ID**: US-002
- **Title**: Mark todo as complete/incomplete
- **Narrative**: As a user, I want to mark a todo item complete or incomplete, so that I can track progress.
- **Scope**: Clicking on a todo item toggles completion styling.
- **Dependencies**: US-001 (new items should also be toggleable via delegated click handler)

## Acceptance Criteria

- **AC-1**: Clicking a todo list item toggles it to completed state (adds completion styling).
- **AC-2**: Clicking the same item again toggles it back to incomplete state.
- **AC-3**: Only clicking the `<li>` toggles completion; clicking the close (×) does not toggle completion.

## Test Cases

### US-002-TC-001: Toggle an incomplete item to completed

- **Priority**: P0
- **Type**: Functional
- **Preconditions**:
  - Todo App is loaded.
  - At least one todo item exists in incomplete state (no completion classes).
- **Test data**: Existing todo item (e.g., `Git - Introduction`)
- **Steps**:
  1. Identify an incomplete todo item in the list.
  2. Click directly on the text area of that item.
- **Expected result**:
  - The item is visually marked completed (checked styling + strikethrough).
  - The item has `checked` and `completed-item` classes applied.
- **Traceability**:
  - **Covers**: AC-1

### US-002-TC-002: Toggle a completed item back to incomplete

- **Priority**: P0
- **Type**: Functional / Regression
- **Preconditions**:
  - Todo App is loaded.
  - A todo item is in completed state (`checked` + `completed-item`).
- **Test data**: Any completed todo item
- **Steps**:
  1. Click directly on the completed todo item.
- **Expected result**:
  - The completion styling is removed.
  - The item no longer has `checked` and `completed-item` classes.
- **Traceability**:
  - **Covers**: AC-2

### US-002-TC-003: Clicking close (×) does not toggle completion

- **Priority**: P1
- **Type**: Negative / UX
- **Preconditions**:
  - Todo App is loaded.
  - Choose an incomplete todo item.
- **Test data**: Any incomplete item with close button
- **Steps**:
  1. Observe the chosen item is incomplete (no completion styling).
  2. Click the close (×) button on that item.
- **Expected result**:
  - The item is hidden (deleted behavior), but it is **not** toggled to completed before hiding.
  - No completion styling is applied as a side-effect.
- **Traceability**:
  - **Covers**: AC-3
  - **Related stories**: US-003

### US-002-TC-004: Clicking outside list items does not toggle completion

- **Priority**: P2
- **Type**: Negative
- **Preconditions**: Todo App is loaded.
- **Test data**: N/A
- **Steps**:
  1. Click on the page background (not on any todo list item).
  2. Click inside the `<ul>` padding area if any (not on an `<li>`).
- **Expected result**:
  - No todo items change completion state.
- **Traceability**:
  - **Covers**: AC-1, AC-2 (by ensuring only LI targets toggle)
