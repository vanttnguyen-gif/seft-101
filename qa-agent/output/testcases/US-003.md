# Test Cases — US-003: Remove a todo item

## User Story

- **US ID**: US-003
- **Title**: Remove a todo item
- **Narrative**: As a user, I want to remove a todo item, so that I can keep my list up to date.
- **Scope**: Close (×) button exists per item; clicking it hides the item.
- **Dependencies**: US-001 (newly added items should also be removable)

## Acceptance Criteria

- **AC-1**: Each todo item displays a close (×) button.
- **AC-2**: Clicking close (×) hides the corresponding todo item.
- **AC-3**: Newly added todo items also have close (×) and can be removed.

## Test Cases

### US-003-TC-001: Initial todo items include close (×) buttons

- **Priority**: P0
- **Type**: Functional / Regression
- **Preconditions**: Todo App is loaded.
- **Test data**: N/A
- **Steps**:
  1. Observe the existing list of todo items on first load.
  2. For at least 3 items, verify a close (×) button is visible on the right side.
- **Expected result**:
  - Each inspected todo item contains a close (×) control.
- **Traceability**:
  - **Covers**: AC-1

### US-003-TC-002: Remove an existing todo item via close (×)

- **Priority**: P0
- **Type**: Functional
- **Preconditions**: Todo App is loaded.
- **Test data**: Choose any existing todo item
- **Steps**:
  1. Locate the close (×) button for the chosen item.
  2. Click close (×).
- **Expected result**:
  - The chosen item is hidden from the list (not visible).
  - Other items remain unchanged.
- **Traceability**:
  - **Covers**: AC-2

### US-003-TC-003: Remove a newly added todo item via close (×)

- **Priority**: P0
- **Type**: Functional / Regression
- **Preconditions**: Todo App is loaded.
- **Test data**: Title = `Temp item`
- **Steps**:
  1. Add a new todo item with title `Temp item`.
  2. On the new item, click close (×).
- **Expected result**:
  - The newly added item becomes hidden.
  - The close (×) interaction works for items added during the session.
- **Traceability**:
  - **Covers**: AC-1, AC-2, AC-3
  - **Related stories**: US-001

### US-003-TC-004: Deleted item is hidden (display:none) rather than removed (current behavior)

- **Priority**: P2
- **Type**: Regression
- **Preconditions**: Todo App is loaded.
- **Test data**: Choose any item
- **Steps**:
  1. Open browser DevTools Elements tab.
  2. Click close (×) on a todo item.
  3. Inspect the corresponding `<li>` element in DOM.
- **Expected result**:
  - The `<li>` remains in the DOM but has inline style `display: none`.
- **Traceability**:
  - **Covers**: AC-2
