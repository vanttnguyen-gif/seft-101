# Test Cases — US-001: Add a todo item

## User Story

- **US ID**: US-001
- **Title**: Add a todo item
- **Narrative**: As a user, I want to add a new todo item, so that I can track tasks.
- **Scope**: Add item via the input and Add button; item appears in list; input resets.
- **Dependencies**: None

## Acceptance Criteria

- **AC-1**: When the title is non-empty, clicking **Add** appends a new todo item to the list with the entered title.
- **AC-2**: After clicking **Add**, the input field is cleared.
- **AC-3**: When the title is empty (`''`), an alert is shown and no item is added.
- **AC-4**: Newly added items have a close (×) button.

## Test Cases

### US-001-TC-001: Add a new todo item (happy path)

- **Priority**: P0
- **Type**: Functional
- **Preconditions**:
  - Todo App is loaded.
  - Todo list is visible.
- **Test data**: Title = `Buy milk`
- **Steps**:
  1. Click into the todo input field.
  2. Enter `Buy milk`.
  3. Click **Add**.
- **Expected result**:
  - A new list item is appended to the todo list with text `Buy milk`.
  - The new item includes a close (×) button.
  - The input field becomes empty.
- **Traceability**:
  - **Covers**: AC-1, AC-2, AC-4

### US-001-TC-002: Prevent adding an empty todo item

- **Priority**: P0
- **Type**: Negative / Validation
- **Preconditions**: Todo App is loaded.
- **Test data**: Title = *(empty)*
- **Steps**:
  1. Ensure the todo input field is empty.
  2. Click **Add**.
- **Expected result**:
  - An alert is displayed with message `You must write something!`.
  - No new todo item is added to the list.
  - The input field remains empty.
- **Traceability**:
  - **Covers**: AC-2, AC-3

### US-001-TC-003: Add a todo item with a long title

- **Priority**: P1
- **Type**: Boundary
- **Preconditions**: Todo App is loaded.
- **Test data**: Title = 256+ characters (e.g., a repeated phrase)
- **Steps**:
  1. Paste the long title into the todo input field.
  2. Click **Add**.
- **Expected result**:
  - A new todo item is added containing the full entered text (no truncation by logic).
  - The input field is cleared.
  - The new item includes a close (×) button.
- **Traceability**:
  - **Covers**: AC-1, AC-2, AC-4

### US-001-TC-004: Add a todo item with whitespace-only title (current behavior)

- **Priority**: P1
- **Type**: Boundary / UX
- **Preconditions**: Todo App is loaded.
- **Test data**: Title = `   ` (3 spaces)
- **Steps**:
  1. Enter three spaces into the todo input field.
  2. Click **Add**.
- **Expected result**:
  - A new todo item is added (because validation checks only `''`).
  - The item appears visually blank/whitespace.
  - The input field is cleared.
- **Traceability**:
  - **Covers**: AC-1, AC-2

### US-001-TC-005: Input is treated as text (XSS-resistant rendering)

- **Priority**: P1
- **Type**: Security
- **Preconditions**: Todo App is loaded.
- **Test data**: Title = `<script>alert(1)</script>`
- **Steps**:
  1. Enter `<script>alert(1)</script>` into the todo input field.
  2. Click **Add**.
- **Expected result**:
  - A new todo item is added.
  - The literal string `<script>alert(1)</script>` is displayed as text (not executed).
  - The input field is cleared.
- **Traceability**:
  - **Covers**: AC-1, AC-2

### US-001-TC-006: Add multiple todo items sequentially

- **Priority**: P1
- **Type**: Regression
- **Preconditions**: Todo App is loaded.
- **Test data**: Titles = `A`, `B`, `C`
- **Steps**:
  1. Enter `A`, click **Add**.
  2. Enter `B`, click **Add**.
  3. Enter `C`, click **Add**.
- **Expected result**:
  - Three new todo items are appended in order: `A`, then `B`, then `C`.
  - Each newly added item includes a close (×) button.
  - Input field is cleared after each add.
- **Traceability**:
  - **Covers**: AC-1, AC-2, AC-4
