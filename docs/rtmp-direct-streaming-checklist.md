RTMP Direct Streaming Checklist
================================

Pre-Session Preparation (within 12 hours before start)
------------------------------------------------------
- [ ] Confirm the session format is set to `RTMP direct streaming (entire screen)`.
- [ ] Verify that fields hidden for RTMP direct streaming (welcome message, closed captioning, sharing settings, participant name visibility, breakout rooms) are not needed for this session.
- [ ] Align the session start time with the external streaming schedule.

Channel Opening Window (12 hours prior)
---------------------------------------
- [ ] Wait until the session is within the 12-hour window before attempting to open the channel.
- [ ] Select `Open Channel` and confirm that `Server URL` and `Stream key` are automatically populated.
- [ ] Click both the `Server URL` and `Stream key` fields to copy each value to the clipboard.

Streaming Setup
---------------
- [ ] Paste the copied `Server URL` and `Stream key` into the external streaming service application.
- [ ] Validate network and encoder settings in the streaming application before going live.
- [ ] Begin streaming from the external application once setup is complete.

Attendee Experience
-------------------
- [ ] Ensure attendees can access the session from the agenda lobby page.
- [ ] Confirm that attendees remain in the waiting room until the stream starts.
- [ ] Monitor attendee status as the stream becomes visible.

Session Wrap-Up
---------------
- [ ] Notify attendees if they need to leave early using the `Leave` icon.
- [ ] When the stream ends, verify that attendees receive the alert: “This meeting has ended. You will be forwarded back to the lobby.”
- [ ] Confirm attendees return to the agenda lobby page after acknowledging the alert.
